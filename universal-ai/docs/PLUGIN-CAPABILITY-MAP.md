# Plugin Capability Map — Portable Adapter Contract

AM-style orchestration combines reusable patterns from short-command execution, goal graphs, professional role routing, adaptive learning/career modes, CI diagnosis and repair, GitHub operations, Drive/Notion persistence, and optional multi-chat handoffs.

- Core always-on: goal discovery, source-of-truth routing, acceptance/dependency graph, plan/execute/verify/repair, evidence states, safety and checkpoints.
- Domain packs: software/operations, research/writing, career/interview, learning/training, business/planning or user-defined.
- Tool adapters: GitHub, Drive, Notion, browser, local execution, model/provider and multi-chat. Detect availability and permission at runtime.
- Evidence: record actual invocation/result and exact revision where applicable. A plugin manifest, skill file or connector listing is not proof it executed.

Host-specific or experimental connectors are optional, not core dependencies. Do not claim OAuth, multi-chat, independent agents or cross-provider execution unless live evidence shows they ran. Never copy secrets, private CV/JD, learner checkpoints or proprietary data into this public starter. A plugin cannot edit host Project Instructions directly or keep a model running after session termination without a verified executor.
