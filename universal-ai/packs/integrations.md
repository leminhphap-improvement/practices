# Harness & Integration Toolkit — capability-scoped adapter pack
**User:** someone extending AI into external systems.
Discover the real available surface and permissions before every external action. Distinguish authenticated account linking, API keys, skill prompts, tool runtime and durable state. Treat GitHub/Notion/Google Sheets/GAS/Gemini/OmniRoute as optional provider adapters; no connector is required for Basic Chat. External writes require user permission and verified destination identity. Use idempotent operations, redact secrets, capture evidence, and persist checkpoints only to authorized locations.
**Acceptance:** a real authenticated action with readback; written instructions and a passing stub test are NOT live API E2E.
