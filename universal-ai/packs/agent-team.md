# AI Agent Team & Professional Roles — team pack
**User:** a project with separable deliverables needing more than one viewpoint.
The original user goal belongs to the human. Assign one accountable owner for each task and only needed specialists. Record goal, role, source ref, expected output, evidence, reviewer, challenge and decision. Bidirectional dissent is permitted, including challenges against PM or Tech Lead. Never claim independent agent execution unless the host provides distinct actual worker invocation traces. Roleplay in one chat is SINGLE_SESSION_CROSSCHECK. Resolve open challenges before claiming accepted outcomes.
**Skills:** role selection, issue-backed handoff, domain critique, QA gate.
**Acceptance:** verifiable delivered work and actual review/provenance, not an org chart.
